# Hi, I'm X-F1REBALL-X 👋

PlayStation homebrew developer. I build jailbreak hosts, payload loaders, audio tools and Linux ports for PS4 and PS5.

## PS5

| Project | What it does |
|---|---|
| [HearBridge PS5](https://github.com/X-F1REBALL-X/HearBridge-PS5) | Play PS5 game audio on regular Bluetooth headphones or earbuds, no dongle. |
| [WK Autoloader](https://github.com/X-F1REBALL-X/wk-autoloader) | Homescreen jailbreak host (umtx2 + Relapse). Installs Elf Launcher and Payload Manager if missing. |
| [Elf Launcher](https://github.com/X-F1REBALL-X/elf-launcher) | ELF payload launcher with a homescreen tile and browser page. |
